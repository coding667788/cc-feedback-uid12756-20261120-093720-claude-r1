实现终端系统安全团队使用的离线启动证明审计服务。设备只以合成 ID、租户、设备代数和独立的递增启动计数器表示。每次证明含租户绑定的唯一挑战、设备计数器、镜像基线及带顺序号的测量摘要链。校验各步 SHA-256 和模拟见证签名，关键模块只能出现在所选基线定义的位置，且覆盖完整启动链。基线按设备组版本化，支持签名发布、吊销和独立的只读恢复基线。恢复基线只允许发放低权限诊断凭据，不能降低设备已观察到的启动计数器或全权限最低版本。

在 SQLite 中支持独立进程验证证明和颁发本地合成访问凭据。预检可离开事务，提交时必须重验设备当前代数、挑战时窗、基线发布与吊销状态及之前计数器。挑战消费、计数水位、凭据与同 ID 回执原子保存；合法低权限恢复证明也必须推进计数器。换代只取消旧凭据和挑战，保留设备历史水位。

实际子进程固定两个合格证明并发争用、先启用新基线后旧证明到达、恢复基线不能获得一般权限、重新登记不重置防回退水位；终止测试工作进程于水位写入未提交和事务提交未返两处，恢复后按确切请求 ID 重放。构造可验证的合成测量链，另测缺模块、错序、跨租户同名、篡改摘要和恰好到期。

在 Windows 原生 Python 3.12、标准库和 CPU 环境下实现，全部输入自行合成，离线测试。交付源码、README、可重放 cases.json 和自动化测试。提供 python -m solution --input cases.json --output result.json 与 python -m unittest discover -s tests -v。测试须断言具体结果，README 写明规则、输入输出、错误码和实测结果。
